## 2. 环境

- WuYue SDK 1.0：`hardware/.venv-cloud`
- Kaiwu SDK 1.3.1：`hardware/.venv-kaiwu`
- 报告生成依赖：`docs/competition/requirements-report.txt`
- 凭据：仓库根目录 `.env`，已由 `.gitignore` 排除
- 超导设备：只使用 `WuYue-QPU-Baihua`
- 相干光设备：`WuYue-QPU-Qboson-1000`

## 3. 最小复现

```bash
hardware/.venv-cloud/bin/python -m unittest \
  hardware/wuyue_vqc/test_wuyue_vqc.py

hardware/.venv-cloud/bin/python hardware/wuyue_vqc/wuyue_vqc.py \
  --mode train --maxiter 240

hardware/.venv-cloud/bin/python hardware/wuyue_vqc/wuyue_vqc.py \
  --mode cloud-simulator --shots 1024 --timeout 600

hardware/.venv-kaiwu/bin/python \
  hardware/kaiwu_qsnn_photonic/large_scale_qsnn.py \
  --mode sa --samples 400 --sa-eval-samples 8

hardware/.venv-cloud/bin/python scripts/build_cross_route_evidence.py

python3 scripts/build_competition_paper.py
```

真机命令会消耗云资源，且 Baihua 当前返回“维护中”，设备恢复后再执行：

```bash
hardware/.venv-cloud/bin/python hardware/wuyue_vqc/wuyue_vqc.py \
  --mode baihua --shots 1024 --timeout 0
```

## 4. 结果解释限制

相干光、VQC 和经典算法的样本覆盖与硬件预算不同，不应直接据准确率排序。圆环任务显式使用半径特征，属于链路验证任务。现有材料不作量子优势、指数加速或完整 Lindblad QSNN 真机实现声明。
